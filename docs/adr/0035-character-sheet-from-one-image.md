# ADR-0035: 手本の画像 1 枚からキャラクターシート（四面図）を作る

- Status: Accepted
- Date: 2026-10-03

## Context

制作者 2026-10-03「動画生成に使うのに役立つ形式のキャラクターシートを 1 枚の画像から作ることが出来る機能があるといい。
キャラクターアップする時の機能に取り入れられるといい。利用する側は正面などの参考になる画像を用意したら、
それを基に Codex CLI でキャラクターシートを作成するようなもの」。

四面図（識別画像の `four_view`）の受け皿と、生成の参照で優先する規則はもうあった。作る機能は ADR-0029 で後回しにしていた。

## Decision

- **絵のジョブに種類を足す**（`start_frame` / `character_sheet`）。シートはキャラクターを、最初のフレームは Shot を持つ
  （`imageJobViolation` が縛る。マイグレーション 0022 で `shot_id` を null 可にし `character_id` を足した）
  - **Codex は 1 度に 1 枚**なので、絵コンテの画像と同じジョブ・同じ `image` キュー（1 並列）を使う
- **手本は 1 枚**。識別画像のうちシート以外の主の画像（無ければ最初の 1 枚。`pickSheetReference`）。頼んだときに決めてジョブに記す
- **指示**（`compileCharacterSheetPrompt`）
  - 正面・横・背面・斜めの全身を、同じ縮尺で横一列に並べる
  - 無地の明るい背景、文字・ラベルなし
  - 手本の人物をそのまま描く。キャラクターの特徴・説明・色・画風を添える
- **横長で頼み、切り抜かない。** Codex への手順には `composition: 'sheet'` を渡す
  - 場面の絵用の「中央に寄せる」「候補を並べない」を言わない（4 つを並べる指示とぶつかる）
- できたシートは識別画像の四面図に足す。四面図の主が無ければ主にする。前のシートは消さない
- **入口**は 2 つ
  - 画像を落として「新しいキャラクターにする（キャラクターシートも作る）」。キャラクターを作り、画像を入れ、シートを作り始める
  - 素材ビューアのキャラクターの「キャラクターシートを作る」
- 作るのは「使う AI」の画像の欄で選んだ AI（ADR-0032）。状態は直近のジョブで出し、出来事 `image_job.status`（`characterId` 付き）で読み直す

## Consequences

+ 1 枚の画像を落とすだけで、動画の参照に向いたシートが付く（Codex で 1 枚 1 分半ほど。実測 1536×1024、4 つの全身が同じ縮尺で並んだ）
+ シートと絵コンテの画像が同じ順番待ちなので、Codex を同時に 2 つ呼ばない
− 手本が人物の写っていない画像だと、Codex は人物を作ってしまう（検証で確かめた）。手本は人が選ぶ
− 出来の自動点検（顔の一致など）は無い。人が見て、要らなければ消す
