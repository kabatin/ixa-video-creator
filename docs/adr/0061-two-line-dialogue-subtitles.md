# ADR-0061: テロップに訳文の 2 段目を持たせ、セリフの行から字幕を導く

Status: Accepted
Date: 2026-10-26
Decider: Claude（Architect）

## 背景

会話劇の計画（段 1〜4）の段 3。段 1（ADR-0059）で Shot にセリフの行（訳文の欄つき）を、段 2（ADR-0060）で採用 Take の音を
書き出しまで残した。しゃべる動物のコント（9:16）では、上に日本語・下に小さめの英語の 2 段字幕が要る。

調べて分かったこと:

- テロップは本文が 1 つ、見た目（`TextStyle`。strict）も 1 つで、2 段で大きさを変えられなかった。
- テロップを描くのは Remotion（プレビューと本番の書き出し）だけ。ffmpeg の退避用の書き出しはテロップを描かない
  （`ffmpeg-renderer.ts`。drawtext でテンプレートを作り直さない方針）。
- ナレーションの字幕は `syncNarrationTelops` で行から作り直し、`params.narrationLineId` で見分けている。
  手で直した時刻は保たない（時刻の正は行の位置）。保つのは当てた見た目だけ。

**守ること: 今までの MV の出力（絵も音も）は変えない。訳文の無いテロップは 1 字も違わない絵になる。**

## 決めたこと

### 1. テロップの訳文と 2 段目の大きさ

- `TextClipParams.translation?: string`（1〜400 字。セリフの行の訳文と同じ上限）。読めない訳文は捨て、本文は描く。
- `TextStyle.translationScale?: number`（0.3〜1、既定 0.6）。**strict のまま**足した（知らない項目は今も弾く）。
- `text-clip.tsx` は訳文があるときだけ、本文の下に 2 段目の箱を描く。大きさは本文の大きさ（短い辺が基準）× 割合で、
  長い訳文は流し込み幅に収まるまで縮める。書体・色・縁取り・影は本文と同じ。
- 訳文の無いテロップは、2 段目の箱を作らない。足す前の版で控えた HTML（横長・縦長 × 型・見た目・ナレーション）と
  丸ごと同じことを確かめた（`telops-without-translation.markup.json`）。
- api はテロップの訳文を保存の形にそろえる: 空・空白だけは鍵ごと外す（画面で欄を空にすると "" が来る）、文字でない・長すぎるものは 422。

### 2. セリフの字幕（`dialogueTelopClips` / `syncDialogueTelops`）

- 行ごとに 1 枚。層はナレーションと同じ 2、見た目の既定もナレーションと同じ下寄せの帯。
- 印は `params.dialogue = { shotId, lineIndex, placed }`。
- 字は行のセリフ（テロップの上限 120 字を超えたら切って「…」）、訳文は行の訳文を写す（無ければ鍵なし）。
- 当てた見た目・型は引き継ぐ（ナレーションと同じ）。

**時刻の決め方:**

- 採用 Take の音を鳴らす Shot（`takeAudioPlays`。ADR-0060 の規則を domain に出し、timeline と共有した）で、
  話している区間の数が行の数と同じなら、行の順に当てる。区間は Take の時刻なので、切り出し位置と速さで Shot の時刻に直す
  （画面に出ない区間は数えない）。
- それ以外（鳴らさない・音の無い Take・測っていない・数が合わない・無音）は、Shot の尺を行の文字数で割り振る。
- 消音した Shot の声には合わせない（観客に聞こえない声に合わせても意味が無い）。

**手で直した時刻は保つ:** `placed` は作り直しが最後に置いた時刻。今の時刻がこれと違えば手で直したとみなし、
次の作り直しでも手の値（と `placed`）を保つ。印に入れておくので、画面・MCP・取り消し、どこで動かしても同じに効く。

### 3. 話している区間は取り込みで測る（計画からの形の変更）

計画は「worker で `silencedetect` を回して区間を拾う」。**取り込み（media キュー）で 1 度だけ測り、`MediaProbe.speechSegments` に残す**形にした。

- 作り直しは api でも worker でも走る。そのたびに ffmpeg を回すと、api に ffmpeg と素材の取得が要り、Shot を直すたびに遅くなる。
  区間は素材ごとに決まるので、測るのは取り込みの 1 回でよい。
- 測るのは音のトラックがある動画だけ（-35 dB 未満が 0.25 秒続いたら無音。0.15 秒未満の音は物音として数えない）。
- **測れなくても取り込みは止めない。** 鍵が無いのは「測っていない」、空の配列は「測ったが無音」。どちらも割り振りに戻る。

### 4. いつ作り直すか

- **api: Shot を変える口の書き込みが成功したら、作品ごとに 1 回**（ミドルウェア `createDialogueTelopSync` 1 か所）。
  `/shots/{id}…`（直す・消す・採用・外す・分割・取り込み）と `/projects/{id}/(shots|storyboard|edit-batches|timeline)…`。
  口ごとに呼ぶ形は、書ける口が多く、どれかで呼び忘れると黙って古いまま残る（ADR-0060 の仕上げと同じ理由）。
  422 などの失敗した書き込みの後は作り直さない。作り直しに失敗しても元の書き込みは成功のまま（ログに残す）。
- **worker: 取り込みの後**（区間と音の有無が分かるので、採用した後に取り込みが終わった Take でも区間に合う）。
- **セリフの無い作品は書かない。** セリフもセリフの字幕も無ければ読むだけで、差し替えを呼ばない。中身が同じなら書かない。

### 5. 訳文の正は行

- `PATCH /clips/{id}` でセリフの字幕の訳文を直すと、同じトランザクションで Shot の行の訳文へ書き戻し、作り直す。
  画面のテロップの欄も MCP の `edit_clips` もここを通る。
- 取り消しの記録（`clip_edit`）に、Shot の行の「変える前」も入れる（テロップだけ戻すと、行の訳文で作り直されて戻らない）。
- 字幕の字は行のセリフで直す（画面は知らせ、MCP の `edit_clips` は `edit_shots` へ案内して断る）。

### 6. 書ける場所

- 画面: Shot のセリフの各行に「訳文」。テロップのインスペクターに「訳文（2 段目）」と「2 段目の大きさ」（訳文があるときだけ）。
- MCP: `add_telops` と `edit_clips` に `translation`（`edit_clips` は null で外す）。`list_telops` は訳文と `origin: dialogue` を返す。
  `remove_telops` はセリフの字幕を消さずに理由を返す（消しても作り直される）。
- 作品の複製: Shot を先に写し、セリフの字幕の印を写した先の Shot へ指し直す（見た目と手で直した時刻が残る）。

## 確かめたこと

- 区間の拾い方: 実 ffmpeg で作った音（0.3〜1.0 秒と 1.6〜2.6 秒に音）から 2 区間を拾い、無音のトラックからは 0 区間。
  取り込みで、音のある動画の probe に区間が入り、音だけの素材には入らず、測れなくても取り込みは成功する。
- 割り振り・区間の当て方・切り出しと速さの換算・手で直した時刻を保つこと・見た目を引き継ぐこと（domain・generation・api・worker）。
- 訳文の書き戻しと取り消し（行も字幕も戻る）、空の訳文で 2 段目が消えること、長すぎる・文字でない訳文の 422。
- セリフの無い作品: Shot を直してもテロップは 1 件も書き換わらない。訳文の無いテロップの絵は足す前と同じ。
  タイムラインの文書・書き出しの props の控え（ADR-0060 の `mv-without-dialogue.*`）も同じまま。

## 分かっている不足

- 区間の拾い方は無音を見つける簡易なもの。周りの物音が大きい Take では外れやすい（外れたら割り振りに戻り、手で直せる）。
  whisper で拾うのは段 5。
- **この形を入れる前に取り込んだ Take は区間を持たない**（割り振りになる）。測り直す口は無い（取り込み済みは冪等で飛ばす）。
- 手で直した時刻は絶対の位置で保つ。その後で Shot を動かしても、手で直した字幕は付いて動かない（直していない字幕は Shot に付いて動く）。
- 行を並べ替える・途中の行を消すと、何行目かで結び付けているので、手で直した時刻と見た目は同じ番号の行に残る。
- セリフの字幕を手で消しても、次の作り直しで戻る（行に「字幕なし」の印は無い）。画面からの削除は止めていない。
- 訳文は自動で作らない（制作者か MCP の Claude が書く）。
- プレビューで 2 段を目で確かめる（9:16）のは、取り込み後の実機の確認で行う（この段の検証はユニットと HTML の控えまで）。
