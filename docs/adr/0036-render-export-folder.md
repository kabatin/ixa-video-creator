# ADR-0036: 書き出した動画を手元のフォルダに置き、Finder で開く

- Status: Accepted
- Date: 2026-10-03

## Context

制作者 2026-10-03「書き出し画面で生成された動画があるフォルダを開く導線が欲しい。書き出し画面は UI/UX が雑な印象が
あるのでついでに綺麗にしておいて」。

書き出した動画はストレージ（MinIO。Docker のボリューム）の中にしか無く、Finder からは見えなかった。
worker の作業用ファイル（`/tmp/ixa-render-output/render-<preset>-<UUID>.mp4`）は名前から中身が分からず、消えてもよい場所にある。

API はこれまで手元のファイルに書かず、ほかのプログラムも起こさなかった。今回はその両方をする。

## Decision

- **書き出しフォルダ**を `~/Movies/ixa-video-creator/<プロジェクト名>/` に置く
  - 場所は `RENDER_EXPORT_DIR`（絶対パスだけ）で変えられる
  - ファイル名は中身が分かる形にする: `<プロジェクト名> <日時> <画質>[ <範囲>].mp4`
    - 例: `ぼくははると 2026-10-02 22.52.37 プレビュー（720p） 0分00秒〜0分51秒.mp4`
    - 日時はこの Mac の時刻。`:` は Finder で `/` に見えるので使わない
  - 規則は domain の `renderExportFolderName` / `renderExportFileName`。画質の名前（`RENDER_PRESET_LABELS`）は画面と同じものを使う
- **フォルダに入れるのは、開くとき**（`POST /projects/{id}/render-folder/open`）
  - まだ入っていない動画だけを、ストレージから取って書く。今までの書き出しも入る
  - **もう入っているファイルは、大きさが違っても上書きしない**（`~/Movies` は利用者が触る場所。手を入れたものを消さない）
  - 書く口は API の `syncRenderFolder` 1 つ。worker は書かない（名前の規則を 2 箇所に持たないため）
  - 毎回違う名前の `.part` に書いてから名前を変える（途中のファイルを残さない。同時に 2 回押されても書きかけを壊し合わない）
  - 1 本の失敗で止めず、入れられなかったものは理由を返す。出力の素材を消した書き出しは飛ばす（失敗として出し続けない）
  - フォルダを作れない・Finder を開けないときは、何が起きたかと保存先を言葉で返す
- **Finder を開く**: `open <フォルダ>`、または `open -R <ファイル>`（その動画を選んだ状態）
  - Mac のときだけ開く（それ以外は 409 で、画面はボタンを出さず保存先だけ出す）

## 境界（安全）

- 書く先は書き出しフォルダの中だけ
  - 名前から `/ \ :` と制御文字を除き、両端の `.` と空白を落とす（`..` だけの名前は「プロジェクト」になる）
  - `v2.app` のように拡張子に見える終わりは `.` を `_` にする（Finder がフォルダをアプリや書類の束と見なし、`open` が起動しようとするため）
  - そのうえで、解決した場所がフォルダの中かを書く直前に確かめる（2 重の柵）
- 起こすのは `open` だけ。`execFile` で呼び、シェルを通さない（名前に何が入っていてもコマンドとして読まれない）
- 本文が JSON でなければ 415 で断る
  - 項目がすべて省略可能なので、断らないと別のサイトのページから、下調べ（preflight）の要らない送信（`text/plain` など）でファイルの書き込みと Finder の起動を起こせる
- 開くのは **API が動いている Mac の Finder**。別の機械のブラウザから押しても、その機械では開かない
  - 待ち受けは既定で `127.0.0.1`（このマシンだけ）なので、普段の使い方では問題にならない

## 書き出し画面（同時に作り直した）

- 2 列にした
  - 左: 範囲・画質（どちらもカードで選ぶ）・書き出す前の確認（1 行）・「書き出す」
  - 右: これまでの書き出し（1 件 1 行。再生・Finder で表示）と「フォルダを開く」
- 書き出す前の確認は 4 つの状態を混ぜない
  - 問題なし
  - 警告だけ（書き出せる。黄色）
  - 書き出せない指摘（赤。ボタンを止める）
  - 確認できていない
- 警告だけのときに赤い枠で出していた検査の一覧を、黄色にした。画面に HTTP の番号（422）を出すのをやめた
- 日時は UTC をやめ、この Mac の時刻で出す（書き出し画面はブラウザで読み込んでから描くので、サーバとずれない）

## 今回の外

- 書き終わった時点で自動でフォルダへ入れる（worker）
  - 開くときに揃えるので、画面から開く分には要らない。Finder から直接見に行く使い方が要るなら足す
- プロジェクト名を変えたとき、前の名前のフォルダは移さない（残す。次に開くと新しい名前のフォルダへ入る）
- ストレージの口が流し読みに対応していないので、1 本ずついったんメモリに読んでから書く（4K の長い動画では数百 MB を使う）
- 同じ名前になる 2 つのプロジェクトは同じフォルダを使う。同じ秒・同じ画質・同じ範囲の書き出しは同じファイル名になる（あとのものは入らない）
  - ファイル名に内部の ID を足せば避けられるが、Finder で読みにくくなる。起きにくいので今は足さない
