# ADR-0013: Seedance は fal.ai で始め、本制作で BytePlus ModelArk へ移る

Status: Accepted（2026-09-16 改訂。初版の「BytePlus 一本」から変更）
Date: 2026-09-16
Decider: Architect

## Context

ユーザーは動画生成に **Seedance** を使うと決めている。プラットフォームが未定。
利用者は**日本在住の個人開発者**である。

### 初版からの訂正

初版はこの ADR を「BytePlus 一本、秒単価 約 $0.14」で書いた。**2 点を訂正する。**

1. **$0.14/秒 は Volcengine（中国本土）の人民元建て価格から換算した数字であり、
   BytePlus の公式レートではない。** BytePlus の実際のレンジは $0.04〜$0.78/秒 で、
   モデル階層と解像度で大きく変わる。「fal.ai の半額以下」と断定できる根拠はまだない。
   ただし fal.ai のトークン単価が公式の約 2 倍（$14/M 対 $7/M）という報告は複数あり、
   **方向としては BytePlus が安い**と見てよい。
2. **BytePlus の登録障壁を「低」と評価したのは誤り。** USD クレジットカードが必須で、
   カードが無い場合はサポートチケットでの申請になる。「今日から使える」経路ではない。

## Decision

**2 段階で使う。Provider 抽象化（ADR-0004）があるからこれが低コストでできる。**

### Phase 1（縦串を通す）: fal.ai

- **カード不要で今日から始められる。** 初期クレジットで疎通確認が完結する。
- 出力 URL が既定 7 日と長く、ダウンロード処理の実装を急がなくてよい。
- `reference-to-video` が**参照を 12 個（画像/動画/音声 混在）**受け付ける。
  BytePlus の 9 枚より多く、参照解決ロジック（§8）を上限まで試せる。
- webhook と公式 JS SDK があり、非同期キューの実装が素直。
- Phase 1 で生成するのは数十秒程度。**単価の差は無視できる。**

### Phase 6（本制作）: BytePlus ModelArk

- MV 1 本で約 600 秒を生成する段階で初めて単価差が効く。
  fal.ai $0.303/秒 なら約 $180、BytePlus がその半分なら約 $90。**差は約 $90。**
- ByteDance 公式の国際版で、日本が提供国一覧に明記されている。個人と法人の区別もない。
- **同じキーで Seedream の画像生成も使える。** Codex CLI の高volume 運用が不安定だった場合、
  追加契約なしで画像を HTTP 経路へ退避できる（ADR-0012 のフォールバック計画の前提）。
- Phase 1〜5 の間にカード登録を済ませておけばよい。**急がなくてよいことが重要。**

### 移行が安く済む理由

これは Provider 抽象化が実際に価値を出す最初の場面である。

- `VideoProvider` の interface は共通（ADR-0004）。アダプタを 1 本足すだけ。
- 両方のアダプタに契約テストを置くことで、**capability 記述の正しさを相互検証できる**。
  片方だけだと「記述が間違っている」ことに気づけない。
- 移行後も fal.ai アダプタは残す。BytePlus の障害・仕様変更時の退避経路になる（リスク R4）。

### レート制限が設計に効く

BytePlus の報告値は **QPS 2 / 同時タスク 3**。MV 1 本で 120 回前後の生成を回すため、
**同時実行 3 が律速になる**。1 生成 1 分としても 120 ÷ 3 × 1 分 = 約 40 分。

→ `generation` キューの Provider ごとの並列度を**設定で変えられる**ようにする（§20）。
  ハードコードしないこと。実測値で調整する。

## Consequences

+ **今日から着手できる。** カード登録を待たずに Phase 1 を開始できる。
+ 本制作の段階で約 $90 を節約できる。
+ アダプタが 2 系統になり、capability 記述を相互検証できる。抽象化の正しさが実機で検証される。
+ BytePlus 障害時の退避経路が最初から存在する。
− アダプタを 2 本書く工数が増える（各 1〜2 日程度）。
  → 契約テストを共通化して吸収する。抽象化の検証という見返りがある。
− BytePlus の価格・レート制限に未確認の項目が残る。
  → **登録後に実測して ADR を更新する。二次情報のまま本制作に入らないこと。**
