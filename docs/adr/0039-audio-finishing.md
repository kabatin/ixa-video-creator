# ADR-0039: 音の仕上げ（ダッキング・フェード・音量を揃える・字幕ファイル）

- Status: Accepted
- Date: 2026-10-05

## Context

ナレーション（ADR-0038）を入れると、曲と声が同時に鳴る。制作者 2026-10-05 の選択で、
**効果音を置けるように**・**書き出しの音量を揃える**・**BGM のフェードイン・アウト**・**話している語を強調する字幕**を一緒に入れた。

それまで音は曲だけが鳴り、ダッキング・フェード・音量の揃え（ラウドネス）はどこにも無かった。
`measureLoudness`（`packages/media`）はあったが使われていなかった。

## Decision

### 鳴らし方は 1 コマごとの音量で決める

- `TimelineDocument.audio[]` に省略可能な `role`（`voice`。無ければ曲）と `fadeInSec` / `fadeOutSec`、文書に `ducking` を足す（`version` は 1 のまま）
- 音量の形は domain の純関数（`fadeGainAt` / `duckingGainAt`）。**プレビューと書き出しが同じ関数を読む**
  - Remotion は `<Audio volume={(frame) => …}>`、ffmpeg の代わりの道は `volume='式':eval=frame`
- ダッキング: 声が鳴る区間を重ねて 1 本にし、少し前から下げ（attack）、後で戻す（release）。強さは作品の設定（弱め・ふつう・強め）
- フェードは**曲ごと**に持つ。書き出しで一部を切っても、途中からもう一度フェードし直さない
- 効果音（SFX）のクリップにもフェードを足す（省けば付けない。前からあるクリップはそのまま読める）

### 音の大きさ

- **声は取り込むときに揃える**: -16 LUFS を狙い、`alimiter=limit=0.8:level=false` で頭を抑える
  - `level=false` を外すと持ち上げられて -14.8 LUFS / トゥルーピーク +0.1 まで上がった（実測）。必ず付ける
- **書き出しは最後に -14 LUFS（YouTube・SNS の基準）に揃える**（既定オン）
  - ffmpeg の `loudnorm` を 2 回（測る → 直す）。1 回だけ（動的）だと曲の抑揚まで潰れる
  - **映像はそのまま写し、音だけ作り直す**（`-c:v copy`）
  - 揃えた後の大きさを書き出しの行に出す。音が無い・揃えないときはそう言う

### 字幕ファイル（SRT）

- 書き出しフォルダ（ADR-0036）を開くとき、動画と同じ名前で `.srt` を横に置く
- 中身は**書き出したときのスナップショットのテロップ**（手で置いた・歌詞・ナレーションのどれも）。動画に出ている字・時刻と食い違わない
- 前からある書き出しにも後から入る。もう入っている字幕ファイルは上書きしない（`~/Movies` は利用者が触る場所）
- テロップが無ければ置かない。切り替えは付けない（あるものを出すだけなので迷う余地が無い）

### 効果音を置く

- タイムラインの効果音の帯は、ワークベンチでは**空でも出す**。音のファイルを落とすとその秒に置く
- 長さはブラウザで読む（上げた直後はサーバがまだ測っていない）
- 帯で受けた音は画面全体の取り込み（音は楽曲にする）へ**流さない**（`stopPropagation`）
- 置いた効果音はインスペクターで位置・音量・フェードを直す（以前は押すとテロップの欄が出ていた）

## 測った値

| 何を | 結果 |
|---|---|
| ナレーション 3 行 + BGM（フェード・ダッキング）を Remotion で書き出し | -14.1 LUFS |
| 声の取り込み（`alimiter` の `level=false` あり） | -16.3 LUFS / トゥルーピーク -1.8 dBTP |

## 今回の外

- ffmpeg の代わりの道（`ffmpeg-filters.ts`）は、もともとクリップを 1 つも描かない（効果音も鳴らない）。そこは変えていない
- 音の帯を波形で見ながら切る（効果音の波形表示）。置く・動かす・音量までで足りている
