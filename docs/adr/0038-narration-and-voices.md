# ADR-0038: ナレーション（声・原稿・録音・テロップ）

- Status: Accepted
- Date: 2026-10-05

## Context

制作者 2026-10-05「歌詞なしの動画の場合、予告動画とか宣伝動画だったりすることが多いと思うんだけど
Gemini 3.8 Flash TTS もしくは有料なら ElevenLabs とか使ってナレーションを入れられるようにしたいですね。
タイムラインでサウンドとかボイス周りがないのでもしかしたら対応が必要そう。ナレーションの声のイメージを設定出来る個所が必要になりそう。
ナレーションをタイムラインでセットしたら、自動で文字起こししてテロップ入れてくれたら超便利」。
同日の追加: **AI の声と録音の両方**／**曲が無い作品**も想定／**キャラクターごとの声**／**字幕ファイルの書き出し**。

それまで音は曲（MUSIC）だけだった。効果音（SFX）の帯と音のクリップの型はあったが、画面から置く口が無かった。
区切る画面は曲が前提（`MusicGate`）で、テロップは歌詞からしか作れなかった（ADR-0033）。

## Decision

### 形（docs/DOMAIN.md）

- **声（VoiceProfile）**: 作品ごと。名前・使う AI・声の種類・声のイメージ（自然な文）・速さ・音量・言語・テロップの見た目・**誰の声か**
  - 誰の声かは**声の側**に持つ（`character_id`）。1 人に声をいくつも持てる（ふだん・叫び）
- **原稿の行（NarrationLine）**: 1 行 = 1 フレーズ。表示（テロップに出す字）・読み（AI に渡す字）・話す声・演出・**位置（秒）**・テロップを付けるか
- **声の Take（NarrationTake）**: 1 行を声にした 1 回分。**追記のみ**。行が「選んだ Take」を指す（Shot と同じ）
- **声のジョブ（VoiceJob）**: 読む／試しに読む／文字起こし／字の時刻。費用の列を持つ

### 決まり（設計の背骨）

| 場面 | 決まり |
|---|---|
| 声は行ごとに作る | 1 行 = 1 回の生成。**原稿が分かっているので、文字起こし無しで行の時刻 = テロップの時刻**になる |
| 同じものは作り直さない | Take に「同じ生成か」のハッシュ（読み・声・設定）。同じなら前の Take を使う（Gemini の無料枠 1 日 100 回の対策） |
| Take は追記のみ | 上書きしない。行が「選んだ Take」を指す |
| 表示と読み | テロップは「表示」、AI には「読み」。字の時刻は読みに付くので、置き換えた区間ごとに表示へ写し戻す |
| ナレーションの位置 | 行が自分の位置（秒）を持つ。**タイムラインのナレーションのレーンは行の投影**（効果音のクリップにはしない。ADR-0002 と同じ考え） |
| テロップ | ナレーションから作ったテロップは**導かれるもの**。字を直すのは行の「表示」で |
| 録音 | 1 つのファイルを文字起こしして行に分け、各行は同じファイルの区間（`in_sec`〜`out_sec`）を指す。取り込むときに軽いノイズ除去と大きさ揃え |
| 字の時刻 | ElevenLabs と文字起こしは字の時刻を返す。Gemini と Mac の声は返さないので、要るときは「字の時刻を取る」（whisper.cpp・無料）で後から付ける |
| 費用 | 声・文字起こしのジョブに費用の列。**頼む前に予算を確かめる**（画像のジョブはしていない。真似しない）。費用の表示に「声」「文字起こし」 |
| 外に出るもの | 原稿は Gemini / ElevenLabs に送られる。キーはヘッダーだけ・ログに出さない。結果の音は base64 で受ける（外の URL を取りに行かない） |

### テロップは行から作り直す

- 規則は `@ixa/generation` の `syncNarrationTelops` **1 か所**。API（行を直した・並べた・声を選んだ・設定を変えた）と worker（声ができた・文字起こし・字の時刻）の両方が呼ぶ
- **ナレーションの印（`params.narrationLineId`）が付いたテロップだけ**を差し替える。手で置いたテロップ・歌詞のテロップは触らない
- 中身が変わらなければ書き換えない（タイムラインの ID を無駄に変えない）
- **見た目は当てたときに写す**（ADR-0028）。作り直しても今の見た目を引き継ぐ。声の見た目で選び直すのは、テロップがまだ無い行と、話す声・声の見た目を変えた行だけ
- 手でナレーションのテロップを消したら、その行を「テロップなし」にする（付け直さない）
- API と worker が同時に差し替えると、後の側は消す相手が無い（`DbNotFoundError`）。読み直して 1 度だけやり直す
- 長い行は句読点で分け、時刻は字の時刻があればそれ、無ければ**読みのかなの数**で按分する（漢字の数ではない）
- 話している字の強調は、カラオケのように**左から塗る**（字ごとの時刻なので「今の 1 字だけ」はちらつく）。プレビューと書き出しは同じ部品で描く

### 使う AI

| 用途 | 選べるもの |
|---|---|
| 声 | Mac の声（無料・ローカル。仮ナレーション向き）／Gemini 3.8 Flash TTS（無料枠あり）／ElevenLabs（有料）／スタブ |
| 文字起こし | whisper.cpp（無料・ローカル）／ElevenLabs Scribe（有料）／Gemini 3.5 Transcribe（安価）／スタブ |

- 各 AI の注意を画面に出す（Gemini の無料枠は原稿が製品改善に使われ人が見ることがある・音に透かし／ElevenLabs の Free は商用不可）
- API キーは env だけ。**キーがあるだけでは有料の AI に切り替えない**（ADR-0032 と同じ）
- Mac の声は、一覧でナレーションに向く声（Kyoko・Otoya）を先に並べる（名前だけで声を作ると一覧の最初の声になるため）

### 曲が無い作品

- 聴きながら切るに「ナレーションの切れ目で N カットを Shot にする」を出す。先頭・各行の話し始め・最後の行の終わりで区切り、行の間の無音は前のカットに入れる
- 曲のある作品では「ナレーションの切れ目に区切りを置く」と、区切りを話し始めに寄せる吸着（歌い出しの次に強い）
- 作業の流れに「ナレーション」の段。曲が無くてもナレーションがあれば「楽曲」は飛ばしてよい

### 絵コンテと原稿の案

- 絵コンテの案に、その Shot の間に話し始めるナレーションを渡す（`narrationDuring`。歌詞の `lyricsDuring` と同じ決め方）
- 「✦ AI」に「ナレーションの原稿」を足す。材料は作品の方針・作品の長さ（と目安の字数 `narrationCharBudget`）・Shot の流れ。1 行 1 フレーズで書かせる

### 複製（ADR-0037 に足す）

- 項目に「声」「ナレーション（原稿・声の Take）」。ナレーションは声が要る
- 声は写した人・テロップの見た目を指し直す。行は写した声を指す（声を写していなければ「声が未定」）
- 声の Take は同じ音のファイルを指したまま、出どころを `{ type: 'copied', fromTakeId }` にする（元のジョブは別の作品の記録なので指さない）
- ナレーションのテロップの印は写した行へ付け替える。行を写していなければ印を外す（手で置いたテロップになり、作り直しで消えない）
- 声を持っていかなかったときは、キャラクター何人分の声が落ちたかを知らせる

## 今回の外（理由つき）

- **声の複製（クローン）**: 本人の同意の手続きが要る（ElevenLabs は自分の声だけ・Gemini は同意の録音が要る）
- **説明から新しい声を作る（Voice Design）**: Gemini の声の API が出たばかりで、作った声が 1 年で消える
- **ブラウザでマイク録音**: 他のアプリで録ったファイルを入れれば足りる
- **AI で効果音を作る**: 有料。まずは手持ちの音のファイルを置けるようにする
- **翻訳版（英語の字幕・ナレーション）**: 原稿・テロップの作りが固まってから
