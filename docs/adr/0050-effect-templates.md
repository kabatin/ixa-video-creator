# ADR-0050: エフェクトの型（タイムラインに重ねる Remotion の部品）

Status: Accepted
Date: 2026-10-17
Decider: Claude（Architect）

## 背景

60 秒の車のアクションの短編を通しで見たら、もっさりしていて速さが無かった。カットの頭・拍・曲のドロップに
光・寄り・揺れを足したい。タイムラインには VFX トラックと `motion_graphics` のクリップが前からあったが、
レンダラは `[motion_graphics] <templateKey>` の枠を出すだけで、`templateKey` も `params` も自由入力だった。
トランジションの whip_pan と glitch も「モーショングラフィックス機構の上に載せる」として cut に縮退していた。

文から HTML を作らせる案もあるが、プレビュー（Player）と書き出し（renderMedia）が同じ絵になる保証が無く、
直すたびに絵が変わる。人もエージェントも「どの型を、どの強さで」を選ぶ形にする。

## 決めたこと

- **型は 8 種で、domain（`packages/domain/src/timeline/effect-template.ts`）が唯一の正。**
  重ねる型（overlay）: フラッシュ `flash`・光漏れ `light_leak`・スピード線 `speed_lines`・フィルム焼け `film_burn`・
  グリッチ `glitch`・タイトルカード `title_card`。下の絵を動かす型（frame）: 揺れ `shake`・寄りのパンチ `zoom_punch`。
  型ごとに zod の値のスキーマ（範囲・既定値つき、知らない項目は弾く）・既定の尺・使いどころの一文を持つ
- **`parseEffectParams` を保存・描画・画面・MCP の全部が通す。** 知らない型・範囲外の値・知らない項目は
  日本語の理由つきで失敗する。API は 422 で項目ごとに返し、通った値は既定値を埋めて保存する。
  エフェクトは VFX トラックにだけ置ける。DB の形は変えない（`content.params` は前から JSON）
- **画面の項目（つまみ・色・選択・文字）の範囲と既定値はスキーマから読む**（`effect-fields.ts`）。数を書き写さない。
  画面が持つのは言葉と見せ方（割合・format-time の秒・倍）だけ
- **描画は `packages/render/src/effects/` の 1 型 1 ファイル。** どれも「コマの番号と値」だけで決まる純粋な関数で、
  乱れ（揺れ・グリッチ・線の位置）はクリップ（トランジション）の ID から種を取る決まった乱数で引く。
  `Math.random()` を使わないので、Player と renderMedia が同じコマで同じ絵になる
- **frame の型は VIDEO1・VIDEO2 の入れ物を動かす。** `frame-effects.ts` がいまのコマで効いているもの全部を重ねた
  動かし方（位置・大きさ・傾き・横のぼかし・色ずれ・明るさ）を出し、Timeline.tsx が入れ物の CSS transform と
  SVG のフィルタに当てる。動かすコマだけ映像の矩形で切り抜き、黒帯へはみ出させない。暗転・テロップ・重ねる型は外に置くので動かない。
  VIDEO2 も入れ物に入るので、暗転は VIDEO2 も覆うようになった。重ねたずれと傾きは足し合わせた分を覆える大きさまで寄せ、
  端の黒を見せない。フラッシュ・寄りのパンチ・揺れは、値の合計が尺より長くても最後のコマで戻りきるよう縮める
- **重なり順・不透明度・混ぜ方（screen・difference）は部品の要素そのものに付ける。** 外に zIndex や opacity の入れ物を
  被せるとそこが重なりの基準になり、混ぜ方が透明な入れ物とだけ混ざって下の絵に届かない（光漏れがただ濁った）。
  グリッチの反転も `backdrop-filter` でなく `difference` で描く（不透明度 1 未満で消えたため）。画素の検査で確かめている
- タイトルカードの文字の大きさは字数から見積もって決め（書体を測らない）、40 字でも映像の幅に 1 行で収める
- **whip_pan と glitch のトランジションを絵に出す。** 境目を中心に前後半分ずつ（暗転と同じ置き方）。whip_pan は前の Shot が
  加速しながら左へ流れ、次の Shot が右から流れ込み、横にぼけて一瞬明るくなる。glitch は境目に近いほど強く跳ねて色がずれ、
  重ねる型のグリッチと同じ帯を重ねる。重ねる素材を使わないので、尺 0 でも既定の 0.4 秒で効かせる。wipe は縮退のまま。
  境目の前に半分の時間が無いとき（曲の頭のすぐ後）は前後とも縮め、境目を真ん中に保つ。whip_pan の横のぼかしは
  1080 の高さで 24px までに抑える（Player で重かった）
- **知らない型・読めない値は理由つきの枠を出す。** 黙って消さない
- **ffmpeg の退避レンダラはエフェクトを描かない。** `RenderResult` に警告の置き場が無い（Port は変えない）ので、
  作るときに `onOmittedEffects` を必須で渡させ、落としたクリップを知らせる。Remotion の `capabilities.motionGraphics` は true にした
- 画面: エフェクトの帯（VFX）を押すか「＋ エフェクト」（再生位置）で型を選ぶ小窓を開き、置いたらインスペクター
  （`effect-clip`）で開く。重なる相手がいれば上の段へ置く。帯の上で動かす・端を引くのはテロップと同じ
- MCP: `add_effects`（時刻か Shot の頭＋ずらし・型・値・尺）・`list_effects`・`remove_effects`。説明に型の一覧と
  範囲と使いどころ（カットの頭・強い拍・曲のドロップ・タイトル）を domain の一覧から載せる。値は送る前に全部確かめ、
  1 つでも読めなければ何も置かない

## 速さ

予告編の速い編集は、短いカットを速く流すことでできている。エフェクトと同じ理由（もっさりして見える）で、
Shot に**速さ**（`Shot.speed`、0.5〜2.5 倍、既定 1）を持たせた。

- 使うのは `trim` の Shot だけ。`fit`（ADR-0026）は今までどおり Take の長さから速さを決める
- AI に頼む長さは **尺 × 速さ**（`requestedSourceSec`）。1.2 秒のカットを 1.5 倍で流すなら 1.8 秒ぶんを頼む
- 尺 × 速さがモデルの最長を超えるときは**最長で頼む**（`generationSecFor`）。断らない。
  再生は、Take が足りる速さまで落とす（1 倍より下げない。それでも足りなければ今までどおり最後のコマで止まる）
- 頼む長さの決め方は `generationSecFor` の 1 か所。api の組み立て・worker の組み直し・待ち時間の目安・MCP の計画が
  同じ値を使う（食い違うと仕様のハッシュがずれ、`spec_drift` で落ちる）
- `fit` に自動で替えるかは**編集尺**で決める（速さを掛ける前）。速めた Shot を fit に替えると、速さが黙って消える
- 速さ 1 なら頼む長さは今までと同じで、既存の仕様のハッシュは変わらない
- 自動レビュー（黒コマ・ブランド色）は、速さを掛けた後に実際に画面に出る区間（`usedSourceEndSec`）を見る
- 画面はインスペクターの Take の欄に「速さ」と「使い始め」（`sourceInSec`）。一括編集と MCP の `edit_shots` でも決められる

## 今回の外

- **文から絵を作らない。** 型を増やすときは domain の表と `effects/` の部品を足す
- 暗転（dip）は、境目の前に半分の時間が無いとき頭で切ったまま（境目が前寄りになる）。whip_pan・glitch だけ直した
- タイムラインの検査（`validateTimeline`）に「読めないエフェクト」の警告はまだ足していない。描画の枠で分かる
- クリップの不透明度は重ねる型には効くが、frame の型の強さには掛けない
- **Safari で HTML の要素に当てる `filter: url(#…)`（whip_pan のぼかし・glitch の色ずれ）は確かめていない。**
  画素の検査は書き出しの Chromium だけ。プレビューが重い・崩れる場合の手当てもまだ
