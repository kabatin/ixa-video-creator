# ADR-0046: 合言葉で入る。API に門を置く

Status: Accepted
Date: 2026-10-09
Decider: Claude（Architect）。制作者の判断（2026-10-09「3 はまず認証の仕組みを追加しましょうか」。
MCP で Claude・Codex から完全自動で動画生成させる前に入口を閉じる）

## できあがり

- 画面を開くと「合言葉」を聞かれる。入れた端末は 30 日入ったまま
- 合言葉なしでは、LAN の中からでも API が何も返さない（401）
- Claude・Codex（あとの MCP）には、画面の「アクセス用の鍵」で発行した鍵を渡す。いつでも取り消せる
- 書き出し・worker・アップロード・素材の再生は今までどおり

## Context

API は認証が無いまま `API_HOST=0.0.0.0` で LAN に開いていた（制作者の判断で開いたまま）。
LAN にいる誰でも作品を消せ、生成を積めた。自動で動く口（MCP）を足す前に閉じる。

## Decision

### 1. 使う人は 1 人。合言葉は env、鍵は 1 つの表

- 合言葉は `IXA_PASSPHRASE`（12 文字以上）。**無ければ API は起動しない**（`createAuth`）。worker は要らない
- 入ったら 32 バイトの乱数の鍵を発行し、`access_tokens` には**ハッシュだけ**を残す。鍵はクッキー
  `ixa_session`（HttpOnly・SameSite=Lax・30 日）にしか無い
- 自動化用の鍵（MCP 向け）も同じ表（`kind: automation`、期限なし）。ブラウザはクッキー、自動化は Bearer。
  **端末の鍵を Bearer で、自動化の鍵をクッキーで見せても通さない**（取り違えの防止）

### 2. 門はすべての口の前。外に置くのは 3 つだけ

`/health`・`/files/*`（署名付き URL そのものが鍵。Remotion も使う）・`POST /auth/login`。
CORS の下見（OPTIONS）も門の外（ブラウザはクッキーを付けずに送る）。
`createApp` は門を**省略できない依存**として受ける。省略できる形にすると、付け忘れが「全部通す」に化ける。

### 3. よそのページからの書き込みと、合言葉の総当たりを止める

- クッキーで来た POST/PUT/PATCH/DELETE は、`Origin` が `CORS_ORIGINS` にあるときだけ通す（Bearer は見ない）
- 同じ相手が 15 分に 5 回まちがえたら 429（`Retry-After` 付き）。覚えるのは API の中だけ
- 鍵の発行・取り消しは**クッキー（人の画面）からだけ**。自動化用の鍵で新しい鍵を作らせない

### 4. 画面: API の場所をページと同じホストにする

クッキーはホストごとに分かれ、SameSite=Lax は別サイトへの呼び出しに付かない。`localhost:3000` で開いた
画面が `macbookpro.local:3001` を呼ぶと、入ったのに 401 になる。ブラウザの中では API のホスト名を
**いま開いているページのホスト名**にする（ポートと http/https は設定のまま。`sameHostAsPage`）。
Next のサーバ側は設定のままで、来た要求の合言葉のクッキーだけを明示して渡す（`server-api-client.ts`）。

## Consequences

- **LAN は http のまま。** 合言葉とクッキーは LAN の中を平文で流れる（`Secure` を付けられない）。
  HTTPS は iPad などにも証明書が要るので別の段。LAN を使わないときは `API_HOST=127.0.0.1` に戻すのが一番安全
- クッキーの名前は 3 か所に書いてある（API の門・Next のサーバ側・Next の middleware）。
  `auth-cookie-name.test.ts` が突き合わせる
- 自動化用の鍵に「できることの範囲」は無い。MCP を作るときに要れば足す
- 合言葉は `.env` を書き換えて API を再起動すれば変わる。入っている端末の鍵は残る（取り消すなら表の
  `revoked_at`）

## 実機で確かめたこと（2026-10-09）

- curl: 鍵なし 401／合言葉で入る（HttpOnly のクッキー）／一覧 200／SSE がクッキーで流れる／
  よそのオリジンからの書き込み 403／出たら 401／表には 64 文字のハッシュだけ
- 署名付きの素材はクッキー無しで 200、署名を外すと 403
- ブラウザ: `localhost:3000` → 入り口 → 合言葉 → 作品一覧（表紙つき）→ ワークベンチ（39 Shot・通知もつながる）→
  アクセス用の鍵を発行 → その鍵（Bearer）で一覧 200・鍵の発行は 403 → 画面から取り消し → 401
- 書き出し: 門を通して受け付け、Remotion が `/files` から素材を取って最後まで描けた
  （保存は別の既存のバグで落ちた: 同じ範囲を 2 回書き出すと同じ中身になり、素材の表の一意制約に当たる）
