# ADR-0037: 作品を複製する（持っていく項目を選べる）

- Status: Accepted
- Date: 2026-10-05

## Context

制作者 2026-10-04「プロジェクトをコピーして複製出来る機能が欲しい。複製する際に持って行きたい項目を選べると良い。
タイトル・楽曲・キャラクター・ロケーション・ブランド・作品の方針・歌詞の時刻・テロップ・セクション・Shot・絵コンテ・Take、
持って行きたいところだけ持っていけるようにすると超便利」。同日に追加「プロジェクト一覧でプロジェクト削除出来るようにしてほしい。
複製もプロジェクト一覧からも出来るといい」。

作品をまたいで写せたのは「ほかのプロジェクトから取り込む」（キャラクター・ロケーション・ブランド資産だけ。ADR-0034）だけだった。

## Decision

- **入口**: ワークベンチの「ファイル > プロジェクトを複製…」と、作品一覧のカードの「…」（右クリックでも同じ）の「複製…」
  - 画面の中身は 1 つ（`ProjectDuplicateForm`）。ワークベンチに依存しない
  - 一覧の「…」には「削除…」も置く。確認の文言は設定画面の「プロジェクトの削除」と共有する（`project-delete-wording.ts`）
  - 「…」はカードの右下に置く（右上は表紙の絵に重なる）
- **持っていく項目**（既定は全部オン）
  - 作品: 作品の方針、楽曲（解析・セクションも）、歌詞の時刻、テロップ、エフェクト・重ね素材・効果音
  - 素材: キャラクター（Look・画像ごと）、ロケーション、ブランド資産
  - Shot: Shot（区切り・カメラ・トランジション）、絵コンテ、絵（最初のフレーム）、Take
  - セクションは楽曲の解析の一部で、人が直す場所が無い。そのため楽曲にまとめる
- **項目どうしの依存**: 歌詞の時刻 ← 楽曲と作品の方針。絵コンテ・絵・Take ← Shot
  - 画面は外すと頼る項目も外して押せなくし、理由を出す。API は矛盾した選び方を 422 で断る
  - 判定は domain の 1 つの関数（`missingRequirements` / `duplicationProblem`）を両方が使う
- **いつも引き継ぐもの**: 画面の形・大きさ・fps・予算。**持っていかないもの**: AI の絵コンテの案、変更の履歴、書き出した動画、作っている途中の生成、レビューの記録
- API: `POST /projects/{projectId}/duplicate`（201: 新しい作品と知らせ。404: 元が無い。422: 選び方の矛盾・名前が空）

## 写すときの決まり

| 場面 | 決まり |
|---|---|
| 画像・動画のファイル | 写さず、同じ MediaAsset を指す（同じ中身のファイルを 2 つ作れない作り）。作品を消しても論理削除なので相手に影響しない |
| ID | すべて新しく振る。Shot・Take・Look・ロケーション・文字の見た目は付け替え表で張り直す |
| 作品の方針 | コンセプトはいまの版だけ |
| 楽曲の解析 | 最新の解析（手で直した版があればそれも）を写す。解析し直さない |
| キャラクター・ロケーションを持っていかない | Shot の登場人物・ロケーションを外し、件数を知らせる |
| テロップ | 作品の方針（歌詞）を持っていかなければ、文字は残して「歌詞の何行目か」の結び付きだけ外す |
| Shot の状態 | 写さない。持っていった中身から決め直す（Take が無ければ下書き）。ロックは引き継ぐ |
| Take | 外した Take も写してから外す（番号が元と同じになる）。採用・作り直しの系譜・前の Take から作る指定を付け替える |
| Take の生成の記録 | 中の Shot の指定を新しい Shot に書き換え、ハッシュを計算し直す |
| Take のレビュー | 「未レビュー」に戻す。人の判定（採用・不採用の意見）は残す |
| トランジション | 両側の Shot を持っていくときだけ |
| 失敗したとき | 先に全部読んでから書く。途中で失敗したら作りかけの新しい作品を消し、理由を出す（500） |

## 複製した Take の費用

- Take に `copied_from_take_id`（元の Take）を足す（マイグレーション 0025。外部キーは張らない。元の作品が消えても印は残す）
- 印のある Take は、費用の合計・予算の確認・自動の作り直しの回数に数えない（domain の `countsAsSpend` 1 つで決める）
- 費用の内訳に「複製した Take N 件は元の作品で作ったもの（$X）で、この作品の費用には入れていません」と出す。Take のカードは「元の作品で $X」

費用を 0 にするだけでは足りない。自動の作り直しの回数（既定 3 回）に数えられて複製先ですぐ止まり、費用の表示にも見えない件数が混ざる。

## 今回の外

- 複製した作品の画像・動画は、元の作品の持ち物のまま残る（ファイルを共有するため）。いまの画面は作品ごとの素材の一覧を使っていないので見え方は変わらない
- 書き出した動画・AI の絵コンテの案・変更の履歴は写さない（新しい作品で作り直せる。履歴は ID が変わると戻し先が成り立たない）
