# UI 作り直し設計書 — ワークベンチを「ワークベンチの作法」で作り直す

Status: Accepted（2026-09-19 制作者承認。Q1〜Q4 はすべて推奨どおり）/ 8.1〜8.5 実装済み
Date: 2026-09-19
Architect: Claude
前提: `docs/UI-WORKBENCH.md`（Phase 7）/ ADR-0021

Phase 7 で画面は 1 つになったが、**中身は旧ページを箱に入れただけ**の所が多い。
制作者の指摘（2026-09-19）:

> 波形があまり変化が無くてパッと見で意味がない。縦幅を取りすぎ、半分でいい。
> 最初に作ったサイトに引きずられている。ブランド資産を押すとペインが開いて既存ページが中にいるだけ、
> 素材を追加してもツリーに出ない。見た目だけ合わせるのではなく、より直感的な UI/UX にしたい。
> 言ったところだけでなく全体的に見直して。

この文書は、実機（本制作 Project・1440×900）で全パネルとダイアログを見て回った結果と、作り直しの設計をまとめたもの。

## 1. 実機で見た問題（全体の棚卸し）

| # | 場所 | 起きていること | 原因の種類 |
|---|---|---|---|

ワークベンチは「**左で選ぶ → 中央で見る → 右で直す**」の作法なので、ページを箱に入れると作法が 2 つ混ざる。

## 2. 作り直しの原則

| # | 原則 | 何を変えるか |
|---|---|---|
| P1 | **選んだものは右で直す。** インスペクターは Shot 専用ではなく、選んだ物の種類で中身が変わる | Shot・キャラクター・Look・ロケーション・ブランド資産・楽曲 の 6 種 |
| P2 | **中央は見る場所。** 大きな絵・波形・映像だけを置き、フォームを置かない | 素材のタブは「素材ビューア」1 枚に統一 |
| P3 | **左は物の一覧。** ツリーには実物（1 件ずつ）が並び、追加も削除もその場で反映される | 素材はワークベンチ全体の共有状態へ（D5 の拡張） |
| P4 | **保存は 1 通り。** 入力は確定した時点（blur / Enter / 選択）で自動保存し、欄の横に「保存済み」「保存できません: 理由」を出す | 「〜を保存」ボタンをやめる。取り消しは既存の変更履歴に載せる |
| P5 | **箱の中に箱を作らない。** パネル = ツールバー（2rem）+ 本文。区切りは罫線と小見出しだけ | カード・影・p-6 を消す |
| P6 | **主ボタンは 1 パネル 1 つ。** 黄色はそのパネルで次にやる 1 手だけ | 画面全体でも最大 3 つ（書き出し + 2 パネル） |
| P7 | **言葉は作る人の言葉。** px / 秒の小数 / 内部 ID を画面に出さない | ズームは「全体・フレーズ・小節・拍」、時刻は `0:02.67` |
| P8 | **落とせば入る。** ファイルをワークベンチに落とすと、種類を聞いてそのまま登録する | 音 → 楽曲、画像 → 行き先を 1 回だけ聞く |

## 3. 波形（A1〜A3）

### 3.1 なぜ平らに見えるか（実測）

いまの波形は区間ごとの**振幅の最大値**（`apps/audio/src/waveform.py`）。本制作の曲はマスタリングで音圧が揃っていて、
2000 点のうち **90% が 0.71〜0.77** に収まる。描けば平らな四角になる。

同じ曲で測り直した値:

| 指標 | 5% | 50% | 95% | 見え方 |
|---|---|---|---|---|
| 振幅の最大（いま） | 0.68 | 0.74 | 0.77 | ほぼ平ら |
| RMS（音の大きさ） | 0.20 | 0.34 | 0.41 | 少し動く |
| 低域 20–250Hz の強さ | **0.02** | 0.53 | **0.82** | キック・ベースの抜けが明確に出る |
| 中域 250–4kHz | 0.28 | 0.56 | 0.74 | 歌・メロディ |
| 高域 4kHz– | 0.20 | 0.55 | 0.76 | ハイハット・シンバル |

**曲の構造は「大きさ」ではなく「帯域の中身」に出ている。** ブレイクでは低域が消え、ドロップで戻る。

### 3.2 描き方

- **3 帯域の色分け波形**（DJ ソフトの作法）。高さ = RMS、色 = 帯域の比率。低域 = 暖色、中域 = 中間、高域 = 寒色
  （具体の色は `globals.css` のトークンに `--wave-low/mid/high` として足す。ライト / ダークの両方で決める）
- **曲ごとに伸ばす**: 下位 2% と上位 98% の範囲を 0〜1 に引き伸ばしてから描く。音圧の高い曲でも差が出る
- **高さは 80px**（いまの半分）。rem で持つ（5rem）
- **目印は波の外へ**: 小節頭と区切りは波形の上の 12px の帯に刻む。拍は区切りを置くときの吸着にだけ使い、
  **線は間隔が 6px 以上空くズームのときだけ**波の上に薄く描く
- **セクション**は背景の帯（交互に 2 色の薄い地）にし、先頭に名前を出す。線ではなく面で見せる
- **ドロップ**は上の帯に ▼ で出す
- 凡例の 2 行はやめ、`?` の中へ移す

### 3.3 データ

- 音声サービスが `peaks` に加えて `rms` と `bands: { low, mid, high }`（各 2000 点、0..1）を同じ JSON に書く
  （`version: 2`）。**DB もドメインも変えない**（波形は保存先の JSON だけ）
- 画面は `version: 2` なら帯域で描き、古い JSON なら**振幅を曲ごとに伸ばして**描く（再解析しなくても今より読める）
- 既存の曲は「再解析」で v2 になる。ローカルの librosa なので**費用は掛からない**

## 4. 素材（B1〜B4, H1）

### 4.1 ツリーに実物を並べる

```
▾ この Project
   ♪ IXA_CUP_Theme_20260907_02   マスター
   ＋ 楽曲を追加
▾ キャラクター                     ＋
   ▾ 藤本タケピ        ◐ 識別画像 2
       Look: 通常                  ← Look も子として並ぶ
   ＋
▾ ロケーション (0)                 ＋
▾ ブランド資産 (1)                 ＋
   ■ iXA Yellow   #FFD200         ← 色は色見本、画像はサムネイル
```

- 各グループの **＋** で、その場に名前の入力欄が出る → Enter で作成 → 作った物が選ばれ、右で続きを直す
- **1 回押す = 選ぶ**（右のインスペクターが切り替わる）。**2 回押す / Enter = 中央の素材ビューアで大きく見る**
- 件数を見出しに出す。0 件のグループは「＋ 追加」だけを出す
- 検索は名前だけでなく色の値・説明にも当てる
- **ツリーから Shot へドラッグ**: キャラクターをストーリーボードのカードに落とす → 登場人物に追加。
  ロケーションを落とす → ロケーションを設定。落とした先のカードが光る

### 4.2 素材の共有状態

キャラクター（+ Look）・ロケーション・ブランド資産・楽曲を **Provider に持つ**（D5 の拡張。ADR-0021 を改訂）。
作る・直す・消すは Provider の関数経由にし、終わったら手元を差し替える。**ツリー・インスペクター・ビューア・
Shot の選択肢（ロケーション・登場人物）が同じ値を見る。** 追加したのに別の場所に出ない、が構造的に起きなくなる。

### 4.3 素材ビューア（中央上の 1 枚のタブ）

旧ページの箱（素材ごとにタブ）をやめ、**「素材」タブ 1 枚**に選んだ素材の絵を大きく出す。

| 種類 | 中央に出すもの |
|---|---|
| キャラクター | 識別画像（四面図）を大きく並べ、主画像に印。Look ごとの画像を下に。**画像はここへ落として追加** |
| ロケーション | 参照画像のギャラリー。落として追加 |
| ブランド資産 | 色なら大きな色面とコントラスト表示、画像ならその画像 |
| 楽曲 | 曲全体の波形（大）とセクション一覧。ここから「聴きながら切る」へ |

### 4.4 楽曲ダイアログをやめる

楽曲はツリーの物になる。登録は「＋ 楽曲を追加」か**音声ファイルを画面に落とす**。解析の状態・BPM・信頼度・
再解析はインスペクター（楽曲）に出す。**楽曲の「マスター」の切り替えと削除は API が無い**ので出さない（§9）。

### 4.5 ファイルを落として取り込む（H1）

ワークベンチのどこに落としても受ける。

- 音声 → 楽曲として登録 → 解析を始める（ステータスバーに進み具合）
- 画像 → 小さな選択肢「どれの画像ですか？」（選んでいる素材 / 新しいロケーション / ブランド資産）を 1 回だけ出す
- 素材ビューアや Shot のカードの上に落とした場合は、聞かずにそこへ入れる

## 5. インスペクター（C1〜C4）

### 5.1 共通の作り

- 上: 何を選んでいるか（種類のアイコン + 名前 + 状態）。右端に `⋯`（複製・削除など取り消せない操作はここ）
- 中: **小見出し + 罫線で区切った 1 本のスクロール**。タブはやめる（生成とレビューが隠れて見つからない）
- 欄は確定で自動保存（P4）。欄の右に小さく `✓` / 保存中 / 赤字の理由
- 数字は `0:02.67` / `1.97s` で出し、入力は同じ形で受ける。← → で 1 フレーム、Shift で 1 拍ずつ動かせる

### 5.2 Shot のとき

```
CUT-04   0:15.66 – 0:20.99（5.33s）      レビュー待ち   ⋯
─ 時間 ──────────────────────
  開始 [0:15.66]  尺 [5.33s]   ☐ 前の Shot から画を繋ぐ
─ 画 ────────────────────────
  説明 [                                  ]
  mood [tense, cinematic]   カメラ [ミディアム ▾][正面 ▾][35mm ▾][押し ▾]
─ 参照 ──────────────────────
  ロケーション [なし ▾]   登場人物 (藤本タケピ / 通常) ✕   ＋ 追加
─ Take ──────────────────────
  ▣▣▣▣  4 本 / 採用: Take 2   [比較を開く]
─ 生成 ──────────────────────
  モデル [自動 ▾] 本数 [1 ▾]   見積 $0.00 / 残り予算 $249.62
  [Take を生成]                              ← このパネルの主ボタン
─ レビュー ──────────────────
  自動レビュー: 合格   人の判定: [OK][やり直し]  指摘を書く…
```

- **カメラは 1 行の選択に畳む**（いまは 5 つの大きな欄）
- 登場人物は **Look を必ず選ぶ**規則をそのまま守り、選ばないと赤字で止める
- 生成の横に**見積と残り予算**（費用メーターの値を使う。額だけを出さない規則はそのまま）

### 5.3 素材のとき

キャラクター（名前・表示名・説明・識別アンカー・Look の一覧）、Look（名前・説明・基準フレーム）、
ロケーション（名前・説明）、ブランド資産（種類・名前・値・使い方の決まり）、楽曲（題名・解析の状態・再解析）。
**旧ページのフォームは使わず、同じ API を新しい部品から呼ぶ。** 検証（zod）と文言は `lib/*-form.ts` を使い回す。

## 6. 中央と下（D1, F1, F2, G1）

- **タブの中で見出しを繰り返さない。** 情報（BPM・件数）はツールバーに寄せる
- **聴きながら切る**: 操作盤（再生・時刻・音量）をパネルのツールバーへ。波形 80px + 区切りの一覧（折りたたみ）。
  「表示の範囲」ボタン 5 つはやめ、**ホイールで拡大・Shift + ホイールで横送り・ダブルクリックで全体**
- **タイムライン**: ズームを「全体 / フレーズ / 小節 / 拍」に。目盛りと波形の帯を聴きながら切ると同じ部品にする
  （時間軸の見た目と操作を 1 つにする。F2）
- **絵コンテ下書き**: 1 行 1 Shot の表（CUT / いまの説明 / 案 / 採用）。違う所だけ色を付ける。行を押すとその Shot を選ぶ
- **自動で割る**: 独立したタブをやめ、聴きながら切るのツールバーの「セクションから割る…」（小さな吹き出し）にする
- **ストーリーボードのカード**: 登場人物の顔（識別画像の主画像）とロケーション名を小さく出す。ダブルクリックで Take 比較

## 7. Shot 一覧（E1, E2）

- 状態は**文字の小さなバッジ**（「レビュー待ち」など）。点だけにしない
- 行全体を押せる。Shift で範囲、⌘ で追加のチェック（表計算ソフトの作法）
- 見出しを押して並べ替え（番号・尺・状態）。絞り込みは状態のチップを並べる（ドロップダウンをやめる）
- 一括操作はチェックがあるときだけ**一覧の上のツールバー**に出す（下に積まない。折り返さない）

## 8. 見た目の規則（D2, P5, P6）

| 規則 | 値 |
|---|---|
| パネルの本文 | 罫線と小見出し（`text-xs font-semibold text-muted` 大文字化しない）で区切る。カード・影は使わない |
| 主ボタン | 1 パネル 1 つ。他は secondary か文字ボタン |
| 取り消せない操作 | `⋯` メニューの中。確認は殻の `WorkbenchDialog`（medium）で出す（`window.confirm` をやめる） |
| 欄の高さ | 1.75rem。ラベルは欄の左（幅が 320px 未満なら上） |
| 空の状態 | パネルの中央に 1 行 + 次の 1 手のボタン（いまの `PanelEmpty`） |

これは `components/workbench/ui/` に小さな部品（`Section`, `Field`, `AutoSaveField`, `ObjectHeader`, `MoreMenu`）として置き、
すべてのパネルがそれを使う。**旧ページ用の部品（`*-manager`, `*-panel` の大きなカード）はワークベンチから外す。**
サイト側のページ（キャラクター一覧・素材ライブラリ）は当面そのまま残す（§9）。

---

## 9. 変えないこと・できないこと

- **ドメイン・DB は変えない。** 波形の JSON（保存先のファイル）だけが v2 になる
- API は既存のものだけで足りる。ただし次の 2 つは口が無いので出さない（必要なら後で BLOCKED として相談）
  - 楽曲の「マスター」の切り替え・削除・オフセット変更（`updateMusicTrack` が無い）
  - Take の採用を外す
- 取り消し（⌘Z）は、いまと同じく**一括操作だけ**。1 欄ずつの自動保存は取り消せない。
  そのかわり、欄の横に**直前の値へ戻す ↺** を 10 秒だけ出す（画面の中の取り消し。サーバの履歴は増やさない）
- サイト側のキャラクター一覧・素材ライブラリのページは残す（ワークベンチの外からも触れるように）。
  中身は 8.2 の新しい部品に差し替えるかを 8.5 で判断する

## 10. 段階

各段は「typecheck / lint / test が緑」「本制作 Project を 1440×900 で実機確認」を満たしてから次へ。

| 段 | 内容 | Acceptance（抜粋） |
|---|---|---|
| **8.1 波形** | 音声サービスの v2（rms + 3 帯域）、描き方（§3.2）、高さ 80px、古い JSON の引き伸ばし | 本制作の曲でブレイクとドロップが色と高さで見分けられる。再解析前でも今より起伏が出る |
| **8.2 素材の共有状態とツリー** | Provider に素材、ツリーに実物、＋ で作る、選ぶ → 右、ビューア 1 枚 | ブランド資産を＋で足すと、ツリー・Shot の選択肢に**再読み込みなしで**出る |
| **8.3 インスペクター** | 種類ごとの中身、自動保存、Shot のセクション化、見積の表示 | 保存ボタンが 0 個。Shot の全項目が 1 本のスクロールで直せる |
| **8.4 中央・下・一覧** | 見出しの重複をやめる、ツールバー化、ズームの言葉、下書きの表、自動で割るの吹き出し、Shot 一覧 | 1 画面の黄色ボタンが 3 つ以下。一括操作が折り返さない |
| **8.5 取り込みとドラッグ** | ファイルを落とす、ツリー → カードへドラッグで割り当て、楽曲ダイアログの廃止 | 音声ファイルを落とすと楽曲ができて解析が始まる |

## 11. 制作者に決めてほしいこと

| # | 問い | 推奨 |
|---|---|---|
| Q1 | 保存を**自動保存に一本化**してよいか（P4） | はい。欄の横に保存の状態と ↺ を出す |
| Q2 | 波形の色（3 帯域の色分け）は DJ ソフト風でよいか、単色で起伏だけにするか | 3 帯域。ブレイク・ドロップが色で分かる |
| Q3 | インスペクターのタブ（設定 / 生成 / レビュー）をやめて 1 本のスクロールにしてよいか | はい。生成とレビューが隠れて見つからない |
| Q4 | 自動で割る をタブから外し、聴きながら切るの中の吹き出しにしてよいか | はい。主の操作は聴きながら切る |

**回答（2026-09-19）:** Q1〜Q4 すべて推奨どおり。あわせて「楽曲マスターの付け替え・削除」と
「Take の採用を外す」を実装する（API は ADR-0022）。
